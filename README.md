# GDX-VR 公司官网

> 广东创想元宇科技有限公司企业官网

## 技术栈

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- shadcn/ui
- Framer Motion
- React Router 6
- React Hook Form + Zod

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
src/
├── components/
│   ├── ui/       # UI基础组件
│   ├── layout/   # 布局组件
│   └── sections/ # 页面区块
├── pages/        # 页面组件
├── hooks/        # 自定义Hooks
├── lib/          # 工具函数
├── data/         # 静态数据
└── types/        # 类型定义
```
